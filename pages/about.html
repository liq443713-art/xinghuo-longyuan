创作说明 · ABOUT THE WORK

以地图为纸，以星火为墨

《星火陇原》不是一份按时间罗列的史料清单，而是一张可以走进、可以点亮的甘肃红色地图。我们希望历史有坐标，记忆有温度，青年有去处。

《星火陇原——甘肃红色坐标数字巡礼》

作品主题

以甘肃八处红色坐标为线索——两当兵变、南梁、腊子口、哈达铺、会宁会师、山城堡、高台、兰州战役——串起 1932 至 1949 年的陇原红色记忆，并把这段历史与甘肃农业大学“知农爱农、强农兴农”的青年使命连接起来。

设计理念

让记忆落在地图上

为什么是地图

红色故事常常以“地点”被记住：会师的城楼、定方向的药铺、血战的城墙。与其把八段历史平铺成文章，不如把它们放回甘肃的地理轮廓里——让抽象的“精神”重新获得经纬度。点击一处星火，地图会告诉你它在河西、陇中、陇东还是陇南。

视觉语言

颜色取自旧地图与宣纸：墨夜、朱砂、麦金与青灰。夜色的地图像一张行军图，朱砂用来标记路线与星火，麦金来自麦穗与土地。页面中的等高线、邮戳、麦穗纹样与星徽，均由本作品以 SVG 手工绘制，没有使用外部图片与商业字体。

排版与阅读

标题用宋体，引文与题签用楷体，坐标与数据用等宽字体，正文用无衬线体。三种字体的分工对应三种信息：历史叙述、文献引语与地理数据。正文行宽控制在舒适阅读区间，重点信息用朱砂色标出，而不是靠大面积的装饰色块。

签名元素：星火册

地图上的每一个点亮动作，都会在“星火册”里留下一个印章位置。八处坐标全部点亮后，会出现完整的收束提示。我们刻意没有设置积分、排行或虚构的参与人数——星火册只记录你自己的阅读进度，保存在本机浏览器里，可随时清空。这是对“走过”的一种诚实记录。

动效克制

页面只在地图路线绘入、星火点亮与内容入场时使用动效；并完整支持系统的“减少动态效果”设置。我们希望动效服务于理解，而不是制造热闹。

技术实现

页面使用 HTML5、CSS3 与原生 JavaScript 编写，不依赖任何框架、外部字体、CDN 或在线接口。所有本地链接均采用相对路径；图片统一存放在 images/ 目录下。双击 index.html 即可离线浏览，也可以放入任意静态服务器。

地图由 js/data.js 中的边界路径与坐标数据生成，地图点位采用原生按钮，支持 Tab 键导航与 Enter / 空格触发。星火册与青春接力记录使用 localStorage，在不可用环境下自动降级为不保存。

页面在桌面与移动端均可使用，并包含键盘焦点样式、跳过导航链接、屏幕阅读器播报区域与“减少动态效果”适配。

兼容性方面，页面按 Edge 90（Chromium 90）内核能力编写，不使用 :has()、accent-color 等该版本不支持的样式；评审可在 Edge 90.0 及以上版本中直接访问公网部署地址。

数据与图片说明

八处坐标的火星位置依据公开经纬度换算；参考路线为示意连接，不代表精确行军轨迹。甘肃轮廓基于公开行政区划边界数据简化、平滑重绘，仅用于视觉叙事，不作为地理测绘成果使用。
