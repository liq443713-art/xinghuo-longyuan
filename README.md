# 星火陇原 · 甘肃红色坐标数字巡礼

甘肃农业大学第五届红色网页设计大赛参赛作品。  
静态网页 + 原生 JavaScript 交互，无框架、无外部字体、无 CDN，可离线运行。

## 如何打开

- 直接双击 `index.html`，用浏览器打开即可。
- 也可以使用任意静态服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 目录结构

```
red-web/
├── index.html
├── pages/           # 红色坐标 / 长征足迹 / 农大接力 / 创作说明
├── css/style.css
├── js/              # data.js（坐标数据）/ map.js（地图交互）/ main.js（通用交互）
└── images/          # 全部为原创 SVG（地图轮廓基于公开边界数据重绘）
```

目录层次不超过 3 层；本地链接全部使用相对路径；图片统一存放在 `images/` 目录。

## 页面与交互

- **首页**：主题首屏、可点击的甘肃星火地图、八处坐标目录、长征四站、农大桥接。
- **红色坐标**：完整互动地图，点击地图星标或卡片即可点亮并阅读详情；支持按类型筛选、上一处 / 下一处、键盘操作；星火册进度保存在本机浏览器，可随时清空。
- **长征足迹**：腊子口、哈达铺、会宁、山城堡四站时间线，以及红西路军血战高台。
- **农大接力**：1946 年至今的校史、校训校风与“知农爱农、强农兴农”，可写下自己的接力承诺（仅保存在本机）。
- **创作说明**：设计理念、技术实现、原创声明、地图与史料来源。

## 上线到公网（主办方已确认：公网可访问即可，网址/域名均可）

比赛群内承办方已明确：**只要公网能访问，提交域名或网址也可以**。本站为纯静态站点，推荐用免费的 **GitHub Pages**，不用买服务器：

1. 在 GitHub 新建一个**公开仓库**（例如 `xinghuo-longyuan`）。
2. 把 `red-web` **里面的** `index.html`、`pages/`、`css/`、`js/`、`images/` 上传到仓库根目录（不要多套一层 red-web）。
3. 仓库 **Settings → Pages → Build and deployment → Deploy from a branch**，分支选 `main`、目录选 `/ (root)`，保存。
4. 等 1–2 分钟，访问 `https://你的用户名.github.io/仓库名/`，用 **Edge 90.0 及以上版本**逐页检查：首页地图、坐标点亮与筛选、收起详情、星火册、青春接力、创作说明。
5. 在仓库根目录新建一个空的 `.nojekyll` 文件（Add file → Create new file → 文件名 `.nojekyll`，内容留空），可避免 GitHub 的 Jekyll 处理干扰静态文件。

如果 GitHub 访问不稳，也可以用 **Netlify**（打开 app.netlify.com/drop，把 `red-web` 文件夹拖进去）或学校服务器。用服务器时把 `red-web` 上传，Nginx 根目录指向它并开放 80 端口：

```nginx
server {
    listen 80;
    server_name _;
    root /var/www/red-web;
    index index.html;
}
```

> 页面按 Chromium 90（Edge 90）内核能力编写：未使用 `:has()`、`accent-color` 等该版本不支持的样式；`backdrop-filter` 不可用时自动回退为半透明纸色导航。正式提交前请务必在 Edge 90+ 实测公网地址。

## 兼容性

- 评审环境：Edge 90.0 及以上（按 Chromium 90 内核特性编写）；同时适配现代版 Chrome / Edge / Firefox / Safari。
- 响应式适配桌面与手机；支持键盘焦点、跳过导航、屏幕阅读器播报与“减少动态效果”设置。
- 星火册与青春接力记录使用 `localStorage`；在不可用环境下自动降级为不保存，不影响浏览。
