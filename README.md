# 星火陇原 · 甘肃红色坐标数字巡礼

甘肃农业大学第五届红色网页设计大赛参赛作品。  
静态网页 + 原生 JavaScript 交互，无框架、无外部字体、无 CDN，可离线运行。

## 如何打开

- 直接双击 `index.html`，用浏览器打开即可。
- 也可以使用任意静态服务器，例如：

```bash
python -m http.server 8000
```

然后访问 `http://localhost:8000/`。

## 目录结构

```
red-web/
├── index.html
├── pages/           # 红色坐标 / 长征足迹 / 农大接力 / 创作说明
├── css/style.css
├── js/              # data.js（坐标数据）/ map.js（地图交互）/ main.js（通用交互）
└── images/          # 全部为原创 SVG（地图轮廓基于公开边界数据重绘）
```

目录层次不超过 3 层；本地链接全部使用相对路径；图片统一存放在 `images/` 目录。

## 页面与交互

- **首页**：主题首屏、可点击的甘肃星火地图、八处坐标目录、长征四站、农大桥接。
- **红色坐标**：完整互动地图，点击地图星标或卡片即可点亮并阅读详情；支持按类型筛选、上一处 / 下一处、键盘操作；星火册进度保存在本机浏览器，可随时清空。
- **长征足迹**：腊子口、哈达铺、会宁、山城堡四站时间线，以及红西路军血战高台。
- **农大接力**：1946 年至今的校史、校训校风与“知农爱农、强农兴农”，可写下自己的接力承诺（仅保存在本机）。
- **创作说明**：设计理念、技术实现、原创声明、地图与史料来源。

## 兼容性

- 评审环境：Edge 90.0 及以上（按 Chromium 90 内核特性编写）；同时适配现代版 Chrome / Edge / Firefox / Safari。
- 响应式适配桌面与手机；支持键盘焦点、跳过导航、屏幕阅读器播报与“减少动态效果”设置。
- 星火册与青春接力记录使用 `localStorage`；在不可用环境下自动降级为不保存，不影响浏览。
